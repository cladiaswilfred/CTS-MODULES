# EventHub Portal

A responsive browser-based event portal built with HTML5, custom CSS, and vanilla JavaScript (ES6+).

## Overview
Users can:
- Browse upcoming events
- Register for events with dynamic fee display
- View gallery with double-click zoom
- Find nearby events via Geolocation
- Save filter preferences using localStorage and sessionStorage

## Tech Stack
- **HTML5**: Semantic elements, form validation, video, storage APIs
- **CSS3 (Vanilla)**: Custom properties, Grid, Flexbox, media queries (no frameworks)
- **JavaScript (ES6+)**: DOM manipulation, Fetch API, OOP, closures, jQuery (minimal)

## Setup
1. Clone the repo.
2. Internet connection required (FontAwesome, jQuery CDNs).
3. Open `index.html` in a browser.
4. For Fetch API without CORS issues, use a local server (e.g., Live Server).

## Features
### HTML5
- `<nav>`, `<main>`, `<section>`, `<footer>`, `<figure>`, `<figcaption>`
- `<video>` with `oncanplay`
- Form inputs: `required`, `placeholder`, `autofocus`, `pattern`
- `localStorage`, `sessionStorage`
- Geolocation API
- `<output>` for confirmation
- Events: `onblur`, `onchange`, `onclick`, `ondblclick`, `keydown/keyup`, `beforeunload`

### CSS3
- Inline, internal, external styles
- ID, class, grouped, descendant selectors
- Box model (margins, padding, borders)
- Media queries for responsive design
- Flexbox and Grid layouts

### JavaScript ES6+
- Async/await, Promises (fetch)
- Class definitions
- Array methods: filter, map, forEach
- Form validation and DOM creation
- Closures for booking counter
- jQuery fadeIn animation
