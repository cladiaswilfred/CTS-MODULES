About This Portal

Overview of architecture and how things work.

Styling

All styles are custom CSS using CSS custom properties. No UI framework is used.

Organization
  • Theme: Colors in :root of styles.css.
  • Layout: CSS Grid for cards, Flexbox for nav and forms.
  • Responsive: Media queries without framework grid.
Customizing

Edit --accent-1 and --bg-deep in styles.css to change the color scheme.

JavaScript

The app uses ES6+ vanilla JavaScript.

  • Modals: Toggled by adding/removing .show class.
  • Data: Uses fetch() with async/await for mock data.
  • Rendering: Events built with createElement and template literals.
